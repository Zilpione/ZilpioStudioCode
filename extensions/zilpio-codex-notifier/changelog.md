# Changelog

## 0.0.6

- Renamed the extension to Zilpio Codex Notifier across the Marketplace, commands and settings panels.
- Replaced the extension and Activity Bar icon with the Zilpio Gaming logo.
- Kept the extension identifier and settings keys unchanged so existing installations update normally.

## 0.0.5

First release of the Codex Notifier Telegram fork.

- Optional Telegram completion notifications alongside sound and visual alerts.
- Bot token, Chat ID, enable toggle, save button and test message in the Codex toolbar settings and notifier sidebar.
- Global machine-scoped JSON settings; masked token input and sanitized network errors.
- Nonblocking requests with a 10-second timeout and existing completion deduplication.
- Independent extension, command, view and configuration identifiers.
- Preserves the original completion detection and sound options from Dankh917's Codex Finish Notifier.
